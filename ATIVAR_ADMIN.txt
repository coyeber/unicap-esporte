UNICAP ESPORTE — ATIVAR PAINEL ADMINISTRATIVO

1. No Apps Script, substitua o Codigo.gs pela versão desta pasta.
2. Execute configurarProjeto() uma vez.
   - Será criada a aba ACESSOS_ADMIN.
   - Acesso inicial: usuário admin / senha admin.
3. Na aba ACESSOS_ADMIN, troque a senha admin antes de colocar o sistema em produção.
4. Apps Script > Implantar > Gerenciar implantações > Editar > Nova versão > Implantar.
5. Envie os arquivos do frontend para o GitHub e aguarde o novo deploy do Vercel.

NOVAS PÁGINAS
- administrador.html: login do administrador
- painel-admin.html: visão geral, equipes, atletas e atualizações

SEGURANÇA
- O painel administrativo não devolve CPF para o navegador.
- O login administrativo usa sessão temporária no CacheService.
- Mantenha a planilha privada e altere a senha padrão admin/admin.
